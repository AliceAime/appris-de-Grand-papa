## Pour transformer un LLM en répétiteur de leçon 😉  
Il suffit de mettre sa leçon en couper/coller 📋 pour l'apprendre au fil du chat 🧠 ! Ou bien une photo 📸 s'il sait la digérer.  

Lui fournir :  
```json
{
  "instruction": {
    "objectif": "Je souhaite comprendre un concept à travers un échange interactif.",
    "etapes": [
      {
        "etape_1": {
          "description": "Créer un JSON avec la structure du cours, les concepts clés, et une clé de 'maîtrise' pour suivre la progression ('pas abordé', 'en cours', 'acquis')."
        }
      },
      {
        "etape_2": {
          "description": "Poser des questions pour vérifier la compréhension de chaque concept et enrichir le JSON si nécessaire, en mettant à jour la clé 'maîtrise' en fonction des réponses de l'élève."
        }
      }
    ],
    "suivi": {
      "description": "Le JSON est ajusté en temps réel selon la progression de l'élève, avec des informations supplémentaires si un concept n'est pas compris."
    }
  }
}
```

## Pour écrire une chanson 🎶  
1. Aller sur [ChatGPT](https://openai.com/index/chatgpt/) pour générer une chanson 🎤.  
2. [Exemple](https://chatgpt.com/c/67151715-c140-8006-9b39-c4c59323a19c).  
3. Se rendre sur [tad.ai](https://tad.ai/ai-music-generator) pour trouver un titre et copier la chanson générée.  
4. Vous pouvez même choisir le type et le style de la chanson 🎸🎹.

## Pour créer un dessin animé 😍  
1. Se rendre sur [Kling AI](https://klingai.com/text-to-video/77122404).

## Lire une vidéo à l'envers 😇  
1. Se rendre sur [Clideo](https://clideo.com/editor/236741617/export-result).  
2. Cliquer sur "Tous les outils" 🛠️ puis "Rembobiner une vidéo".  
3. Importer la vidéo 🎥.

## Créer son clone en vidéo 👩🏼‍🤝‍👩🏼  
1. Aller sur [HeyGen.com](https://app.heygen.com/home).  
2. Sélectionner "Avatar vidéo" 👤 et importer une photo.  
3. Compléter les infos : nom, genre, voix, texte 💬.  
4. Générer la vidéo.  

---

## Créer une mélodie grâce à une IA 🎵  
1. Aller sur [Deepseek Artifacts](https://deepseek-artifacts.vercel.app/).  
2. Entrer un prompt 🎹 : "Fais-moi un synthétiseur qui joue la partition de (ta chanson)".  
3. Si ça ne fonctionne pas, ajouter des données au prompt.  

**Alternative** : utiliser [Claude.ai](https://claude.ai/login?selectAccount=true&returnTo=%2Fchat%2F89535ced-ade2-4718-85b7-124ddfea780%3F). Copier le code Python 🐍 et le coller sur Deepseek Artifacts.

## Créer un câble virtuel 🖧  
1. Installer **Virtual Cable** 🎧.  
2. Redémarrer l'appareil 🔄 et aller dans les paramètres du son.  
3. Sélectionner le câble pour l'entrée et la sortie audio 🔊.  

**Attention ⚠️** : si le câble n’est pas configuré correctement, ça ne fonctionnera pas !
